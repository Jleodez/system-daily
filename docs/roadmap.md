# SYSTEM — Roadmap

SYSTEM is intentionally documented with a clear separation between what exists today and what may come later.

The roadmap is not a promise of features. It is a record of plausible next steps based on real use of the current prototype.

## CURRENT

Implemented today:

- Fixed daily routine with eight blocks
- Pending, Done, and Missed states
- 10 XP for completed routine blocks
- XP-based levels
- Daily completion count, percentage, and progress bar
- Focus sessions connected to routine blocks or Free Focus
- Focus, Short Break, and Long Break phases
- 25/5 and 50/10 presets
- Custom focus and break durations
- Start, Pause, Resume, Restart, Skip, and Cancel controls
- Long break after four completed focus cycles
- Completion sound and adjustable volume
- Test-sound control
- Optional browser notifications
- Auto-start next phase
- Fullscreen focus mode
- Daily focus analytics
- Focus breakdown by task and inferred domain
- Focus-session history
- Weekly completion summary
- Focus streak
- Total XP and current level
- Persistent server-side routine activity, timer state, preferences, XP, and focus sessions

## NEXT

Near-term improvements worth exploring:

- Expose routine title editing in the interface
- Allow routine times and block order to be edited
- Add a simple way to reset or customize the daily structure
- Add richer historical views using already-saved activity
- Improve review of previous days and completed focus sessions
- Add optional notes or reflection to routine blocks and focus sessions
- Refine mobile interaction and visual density where needed
- Continue improving timer resilience across browser visibility/state changes

## LATER

Longer-term possibilities:

- Flexible task creation beyond the fixed routine
- Multiple user profiles and account-aware data separation
- Calendar integration
- External productivity-tool integrations
- More detailed progress visualizations
- Reusable routine templates
- Export / reporting workflows
- Standalone implementation outside ChatGPT Sites
- Open-source code release if/when the standalone implementation is ready

## Product guardrail

Any future feature should answer at least one of these questions:

1. Does it make the daily plan easier to follow?
2. Does it protect or improve focused work?
3. Does it make meaningful progress easier to understand?

If the answer is no, it probably does not belong in SYSTEM yet.
